## Unicode data (snug/unicode)

The optional Unicode tables — the npm package's `@3sln/snug/unicode` entry
(`src/unicode-tables.mjs`) and the crate's `snug::unicode_tables` — are
general-category code point ranges derived from the Unicode Character
Database, Unicode 16.0, as exposed by Node's ICU data. They are generated by
`tools/unicode/gen-tables.mjs` in the snug repository. That data is
